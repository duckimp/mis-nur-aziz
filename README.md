# MI Nur Aziz Website

Website resmi MI Nur Aziz yang dibangun menggunakan Astro Framework.

## Fitur Utama
- **Beranda**: Ringkasan visi, berita terbaru, dan CTA pendaftaran.
- **Profil**: Sejarah, visi-misi, dan struktur organisasi.
- **Akademik**: Informasi kurikulum dan unduh dokumen PDF.
- **Guru & Staff**: Daftar tenaga pendidik dan kependidikan.
- **Galeri**: Dokumentasi kegiatan dengan fitur lightbox.
- **PPDB**: Informasi pendaftaran online dengan barcode.
- **Kontak**: Lokasi Google Maps dan integrasi WhatsApp/Email.

## Pengembangan Lokal

```bash
# Instalasi dependensi
npm install

# Menjalankan server pengembangan
npm run dev
```

## Deploy ke Vercel

Proyek ini siap untuk di-deploy ke Vercel. Cukup hubungkan repositori GitHub Anda ke Vercel, dan biarkan Vercel mendeteksi pengaturan Astro secara otomatis.

**Build Command:** `npm run build`
**Output Directory:** `dist`
